# 内置模板：省级重点研发计划

## 适用场景
各省科技厅重点研发计划、地方重大科技专项。

## 目标输出章节
1. 国内外现状及发展趋势（2000字以内）
2. 主要研究内容（2000字以内）
3. 技术路线（1000字以内）
4. 产业化前景与经济效益（独立章节）

## 国内外现状必填要素
- 国内外研究现状
- 代表性机构与成果
- 发展趋势
- 地方产业需求对接（强调本省/市产业痛点）
- 可包含"城市比较"（本省 vs 国内先进省份）
- 可包含"本地单位线索"（省内高校、企业、科研院所）

## 研究内容与技术路线必填要素
- 拟解决的关键技术问题（对接地方产业需求）
- 研究内容（按任务分解）
- 技术路线（分阶段）
- 创新点（强调技术突破与产业应用价值）
- 考核指标（量化）

## 特殊约束
- 强调地方特色、产业落地、经济效益
- 需明确省内企业参与、产学研合作
- 引用：GB/T 7714-2015
